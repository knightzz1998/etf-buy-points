# ETF 策略 v2 设计（基于现有策略 + 回测）

> 定稿：2026-11-05　依据：`workbench/backtest_v2.py`
> 数据：326 只策略池 × 约 3 年日线；t 日收盘出信号、t+1 收盘入场；双边成本 0.05%

---

## 零、一句话

**只在进攻档开新仓**；进攻档用博主第一买点；**按距 MA20 由远到近排序**；同时最多 2 只；破 17 日线次日离场。

---

## 一、回测依据

同一池、同一区间、同一出场规则下比较六种做法：

| 策略 | 笔数 | 胜率 | 均收益/笔 | 盈亏比 | 总收益 |
|---|---|---|---|---|---|
| 博主法·全信号（不筛档位） | 120 | 28.3% | −0.49% | 0.77 | −59.3% |
| 博主法 + 跳过中性档 | 114 | 29.8% | −0.26% | 0.86 | −29.3% |
| **博主法 + 仅进攻档** | **62** | **43.5%** | **+1.46%** | **1.82** | **+90.8%** |
| 博主法 + 防守档防御组低吸 | 36 | 33.3% | −0.62% | 0.59 | −22.4% |
| 规格书原版（五条件 + 距 MA20 升序） | 162 | 37.7% | +0.08% | 1.07 | +12.9% |
| 规格书修正（仅进攻档 + 距 MA20 降序） | 62 | 33.9% | +0.80% | 1.28 | +49.7% |

三条结论：

1. **档位是决定性的**。同一套买点，只在进攻档执行时均收益 +1.46%、盈亏比 1.82；不筛档位 −0.49%；筛掉中性但仍含防守 −0.26%。
2. **防守档低吸不成立**（−0.62%/笔）。规格书里「防守档只买防御型」在博主信号上没有正期望；防守档的正确动作是不新开仓。
3. **博主买点优于规格书五条件**（+1.46% vs +0.80%，盈亏比 1.82 vs 1.28）。规格书的五条件更适合当「允许池」，不适合当买点。

## 二、规则

### 2.1 档位（决定能不能开仓）

```
上证收盘 >= 上证MA20  且  创业板收盘 >= 创业板MA20  → 进攻档
仅其一成立                                        → 中性档
两者都不成立                                      → 防守档
```

- 盘中用「实时指数价 + 动态 MA20（前 19 日收盘 + 现价）」判定，**以收盘为准**。
- 进攻档：可开新仓。
- 中性档：不新开仓。
- 防守档：不新开仓，只做持仓管理。

### 2.2 标的池

```
股票型（宽基 / 行业主题）
规模 ≥ 10 亿（份额 × 市价）
成交额 ≥ 1000 万
溢价率 ≤ 3%
上市 > 60 天
```

当前落在 326–328 只。跨境/商品/债券/货币不在池内（回测未覆盖，且跨境溢价常 >3%）。

### 2.3 买点（仅进攻档执行）

```
C1  周线 KDJ(9,3,3) 近 6 周 J 谷底 <= 20
C2  本周 J > 上周 J（回勾）
C3  现价 > MA17
C4  MA5 > MA17
C5  周线 J < 80
```

排序与容量：

```
排序 = 距 MA20 由远到近 → 成交额由大到小
容量 = 同时最多 2 只，单只 <= 20% 仓位，现金 >= 20%
```

> 为什么是「由远到近」：回测里按「距 MA20 最近」取前 2 的超额是 −0.33%/5 日、−0.46%/20 日；
> 按「最远」是 +0.20% / +0.99%。进攻档更明显：−0.41%/−1.15% 对 +0.55%/+1.25%。

### 2.4 持仓管理（任何档位都执行）

```
收盘跌破 5 日线        → 减仓（降仓位）
收盘跌破 17 日线      → 次日离场（生命线）
周线 J >= 80          → 卖一半
持有满 45 个交易日    → 时间止损
```

### 2.5 明确不做

- 中性档、防守档不开新仓（回测为负期望）。
- 不做「抄底」：防守档的防御组低吸在博主信号上为负。
- 不在溢价 >3% 时买入（硬规则）。

## 三、与规格书 v1.0 的差异（均为回测改动）

| 项 | 规格书原文 | v2 |
|---|---|---|
| 排序优先级 | 距 MA20 更近 | **距 MA20 更远** |
| KDJ 周期 | 未写 | **日线 (9,3,3)** 用于规格书五条件；博主买点仍用周线 J |
| 中性档 | 五条件 + 8% + 0.75 仓 | **不开新仓** |
| 防守档 | 只买防御型、3 成 | **不开新仓** |
| 煤炭 | 防御名单 + 黑名单冲突 | 保留黑名单（回测支持） |
| 进攻档条件 | C1&C2&C5 | 直接用博主第一买点（+1.46% vs +0.80%） |
| 买点定义 | 五条件 | 博主四条件 + J<80 |

## 五、局限

- 样本约 3 年、单一市场周期；策略在熊市可能长期没有信号（这本身是设计意图）。
- 池子按当前规模筛选回溯，存在幸存者偏差。
- 回测未计止损在组合层面的影响，也未计滑点；实际按 2 只、20% 仓位执行时，单笔亏损上限需自行控制。
- 62 笔样本，统计显著性有限；建议先模拟 3 个月再上实盘。
- 「距 MA20 最远」在极端行情下可能买在短期顶部，v2 用「距 MA20 上限」不设限是回测结果，实盘可加 12% 硬上限。
