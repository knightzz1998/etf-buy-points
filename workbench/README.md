# ETF 买点工作台

全市场 A 股 ETF 的博主波段法信号看板。构建期把日线指标烘焙成静态数据，打开页面后用东方财富实时快照补当日价，
盘中就能看到「哪些 ETF 符合买点、哪些差一项条件」。

线上站点由 ZCode Sites 托管，纯静态、无后端常驻进程。

## 策略 v2（2026-11-05 回测定稿）

**档位先行，只在进攻档开新仓**：上证与创业板均在 MA20 上方＝进攻档；仅其一＝中性档；都否＝防守档。
回测（326 只 × 3 年，t 日信号 / t+1 收盘入场 / 破 MA17 次日离场）：博主买点在进攻档 62 笔、胜率 43.5%、均 +1.46%、盈亏比 1.82；
不筛档位或含中性/防守为负期望。非进攻档只做持仓管理（破 17 日线离场、破 5 日线减仓）。

买入排序：**距 MA20 由远到近**（趋势越强越前），每日最多 2 只。回测显示按「距 MA20 最近」排序超额为负（−0.33%/5 日），按「最远」为 +0.20%/5 日。

## 信号口径

与仓库既有的 `kdj17_scan.py` / `daily_signal.py` 保持一致：

| 档位 | 条件 |
|---|---|
| 🟢 可以买入 | 周线 KDJ(9,3,3) 近 6 周 J 谷底 ≤ 20 且本周 J 回勾 ｜ 现价 > MA17 ｜ MA5 > MA17 |
| 🔵 可以加仓 | 多头中未破 5 日线（回踩不破、站稳 5 日线） |
| 🟡 可以减仓 | 多头中跌破 5 日线；或周线 J ≥ 80 |
| 🔴 该离场 | 跌破 17 日线（生命线） |
| ⚪ 观望 | 站上 17 日线但 5 日线未金叉（修复期） |
| ⏳ 接近买点 | 只差一项：MA5 距金叉 ≤1%，或跌破 17 日线 3% 以内且 MA5 仍在上方 |

- MA5 / MA17 / MA60 为简单移动平均；周线按周高/周低/周收盘聚合，与 pandas `resample("W-FRI")` 等价。
- 盘中用实时价替代当日 K 线与当周 K 线的收盘，因此均线和周线 J 是动态值，收盘后才算最终确认。
- 溢价率 = 市价 / IOPV − 1，取自东财折价率取负；≥3% 在详情里标红提示禁止买入。

## 使用

```bash
# 1. 更新数据（复用 data/etf_hist_cache 日线缓存，只补缺失的）
cd etf-buy-points
python3 workbench/build_data.py

# 2. 本地预览
cd workbench
PORT=8123 node static-server.mjs dist

# 3. 组装部署目录
python3 workbench/publish.py --stage
```

数据每天更新一次即可：`build_data.py` 会按行情日期判断缓存是否过期，收盘后再跑一次就能覆盖当日 K 线。
页面上的「指标基准日」会显示 `base.json` 的数据日期；若它落后行情日超过 3 天，页面会顶栏提示重建。

## 数据来源

| 用途 | 接口 |
|---|---|
| 全市场 ETF 实时快照 | 东方财富 `push2.eastmoney.com/api/qt/clist/get`（16 只/页 × 17 页，并发 0.4 秒拉完） |
| 日线历史 | 东方财富 `push2his.eastmoney.com/api/qt/stock/kline/get`（前复权，约 3 年） |
| 指数实时（档位） | 东方财富 `push2 .../ulist.np/get`（上证 000001、创业板 399006） |

浏览器端直接请求东财接口（该接口返回 `Access-Control-Allow-Origin: *`），不经过中间服务器。
行情只在页面打开时拉取，不做后台轮询；自动刷新默认 3 分钟，可调 30 秒 / 1 分钟 / 3 分钟 / 5 分钟或暂停；切回标签页时若距上次拉取已超过设定周期会立即补拉一次。

## 已知限制

- 页面本身不写任何数据，指标依赖构建产物；跨多日不重建会让均线失真（页面会提示）。
- 233 只新上市 ETF 因日线不足 130 根被跳过，不在看板内。
- 同赛道去重只保留成交额最大的一只，其余在名称下显示「同类 N」。
- 档位用实时指数价与动态 MA20 判定，盘中会翻转；以收盘价为准。
- 非进攻档页面仍会列出买点条件，但标记「不新开」，只作观察与持仓管理。
- 信号为规则化提示，不构成投资建议；盘中破位等尾盘确认，收盘破 17 日线次日才执行离场。
